Question Paper Generator

To add a question to the question paper please write the full question under the question column and write all of its subsequent options in the columns Option 1, 2, 3 and 4 where 1, 2, 3 and 4 represent options A, B, C and D respectively. None of the fields can be empty and the Answer field only accepts 1, 2, 3 and 4. Use the Add button to add another question and the Finish button to finish the paper.
